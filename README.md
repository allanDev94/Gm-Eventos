# GM Eventos

Sitio web oficial de **GM Eventos**, productora de eventos especializada en DJ, sonido profesional, iluminación y producción integral de celebraciones.

🌐 Sitio web oficial:

https://gmeventos.cl

---

## 🚀 Descripción

GM Eventos es un sitio web corporativo desarrollado para representar la identidad digital de una productora de eventos, ofreciendo una experiencia moderna, responsive y optimizada para presentar sus servicios y facilitar el contacto con clientes.

El proyecto permite mostrar:

- Servicios de producción de eventos.
- Experiencias y eventos realizados.
- Información de la empresa.
- Canales de contacto y cotización.

## ⚙️ Instalación local

Clonar repositorio:

```bash
git clone https://github.com/allanDev94/Gm-Eventos.git
```

Ingresar al proyecto:

```bash
cd Gm-Eventos
```

Instalar dependencias:

```bash
npm install
```

Ejecutar entorno de desarrollo:

```bash
npm run dev
```
